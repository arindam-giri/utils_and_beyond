Run Fully Offline

By default this file loads Mermaid from a CDN. To make it work without any internet connection, bundle the library locally:

  1. Download mermaid.min.js from https://cdn.jsdelivr.net/npm/mermaid@10/dist/mermaid.min.js
  2. Place it in the same folder as this HTML file.
  3. Open this HTML in a text editor and find the <script src="https://cdn.jsdelivr.net/npm/mermaid...> line near the top of <head>.
  4. Replace it with <script src="./mermaid.min.js"> and save.
  5. Reopen the file — the header badge will still read READY and the app works with no network.
